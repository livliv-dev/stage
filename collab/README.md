# 本地 / 自托管朋友联播

此目录是 Stage 的独立信令服务，不渲染角色、不代理 AI、不保存模型。当前为开发版，未部署。

```sh
npm --prefix collab ci
npm --prefix collab start
```

默认只监听 `127.0.0.1:5234`。启动 Stage，顶栏「联播」中选择一个自己的角色和麦克风开关，创建并复制邀请码。另一位在同机测试页选择自己的角色、粘贴邀请码，房主接纳后双方才分享模型、姿势和声音。结束房间会移除临时角色。每人最多分享一个角色，最多四人，布局各自控制。

同机测试可用不同浏览器 profile，避免两个编辑页共用同一条输出 BroadcastChannel。普通浏览器和桌面客户端使用相同协议。系统朗读只在本机，角色接口语音和麦克风通过 WebRTC 同步；收到的声音只在编辑器播放一次，OBS 采集应用音频。本地录制会混入朋友声音。录自己的麦克风仍需在录制面板开启。

## 信令配置

| 环境变量 | 默认 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 监听网卡；公开监听应由部署者明确配置 |
| `PORT` | `5234` | 端口 |
| `ALLOWED_ORIGINS` | 空 | 允许的网页 Origin，逗号分隔；另外允许本地 HTTP 与 `livliv-stage://app` |
| `ICE_SERVERS` | `[]` | JSON 格式的 WebRTC `RTCIceServer[]`，正式服务应使用短期 TURN 凭证 |
| `RELAY_ONLY` | `0` | `1` 时强制通过配置的 TURN 中继 |
| `MAX_CONNECTIONS` | `256` | 同时在线的连接总数 |
| `MAX_SOCKETS_PER_IP` | `4` | 每个 IP 同时在线的连接数；IPv6 按 /64 计 |
| `MAX_ROOMS_PER_IP` | `2` | 每个 IP 同时开着的房间数 |
| `TRUST_PROXY` | `0` | `1` 时按 `X-Forwarded-For` 的最后一跳认 IP。放在反向代理后面时要开（不开所有人都算作代理的 IP），直连时不要开 |

网页生产环境使用 WSS，由反向代理终止 TLS。客户端只对本机和私有网段（RFC 1918、IPv6 ULA）接受 `ws://`，其他服务地址必须是 `wss://`；加入的人在连接前能看到邀请里的服务地址。服务仅提供 `/room` WebSocket 与 `/health`，不列出房间。邀请包含随机房间及凭证，持有者可以申请加入，接纳/移除仅房主可做；房主断开即结束房间。连上后 10 秒内没有创建或加入房间的连接会被关闭；每个连接有消息速率上限，超出的消息被丢弃，持续超出就断开。当前没有账号体系，配额只按 IP 计，不能直接作为公开服务。

## 数据边界

可靠 DataChannel 传选中的角色文件；无序 DataChannel 最多 20 fps 传 Player 最终姿势。角色包最多 64 MiB / 512 文件，按 16 KiB 分片并等待背压。接收端检查路径、声明大小、总量、清单和分片完整性，再交给 Player 做格式检查。相机图像、其他舞台素材、密钥不会进入这个协议。

每对成员独立 WebRTC 连接；所有人互听。发送声路只取本人麦克风和所选角色的 Player Speech 流，远程流不会回灌。静音朋友仅改变本机监听与录制增益。共享角色更换或删除时结束本次连接；临时角色不写入场景文件/角色库。参与者会收到可渲染资产，不承诺防复制。

公网还需配置并验证 STUN/TURN。当前测试范围见测试脚本，不代表真实跨网、掉线恢复或长时间通话验收。

```sh
npm --prefix collab test
node --disable-warning=ExperimentalWarning stage/test/collab.mjs
```

第二条在仓库根目录运行，需 Stage 依赖与 Playwright Chromium。它启动临时 relay 和 Vite，用三个隔离页面测试真实 WebRTC、三种格式、模型/姿势/音频、输出和离开后的录制，不访问外部服务。
