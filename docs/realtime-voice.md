# Stage 实时语音

更新：2026-11-15。提供可选的 WebRTC 实时语音通话和内容反应，保留原有按键录音、文本模型及 TTS 路径。

## 使用

1. 添加并载入一个「AI 来演」的本机角色。网页版点击底部控制台的「实时语音」；桌面版在底部控制台的「更多方式」里选「实时语音通话」。
2. 点击弹窗中的「设置模型与声音」，在设置的「实时语音」中选择百炼或 OpenAI，填写接口地址、实时模型和音色。密钥可复用已配置的同服务商密钥，也可单独填写；仅保存在本机，不进入项目包。回到通话弹窗选择通话角色。私聊还是公开记忆按控制台状态行的范围标签；输出窗口、录制、联播或直播间开着时一律公开。
3. 设置接话方式与时长上限，点击「开始实时语音」。连接及模型配置确认后才开始向模型传送麦克风音轨。通话不自动发起开场白。
4. 可以直接说话和插话，也可以发送文字。暂停停用发送音轨并中止回应；结束释放麦克风、WebRTC、音轨、声音节点和订阅。更换麦克风或移除角色会结束当前通话。

默认百炼模型为 `qwen3.8-omni-flash-realtime`，音色 `Tina`。该模型需要百炼工作空间专属域名，例如 `https://WORKSPACE.cn-beijing.maas.aliyuncs.com`；地区、密钥和模型权限须匹配。不会自动把旧百炼公共域名用于此默认模型。[百炼接入说明](https://help.aliyun.com/en/model-studio/realtime)

可以直接填写工作空间复制出来、以 `/compatible-mode/v1` 结尾的完整地址。Stage 会使用同一工作空间的实时语音接口，无需手动改写请求路径。

OpenAI 默认模型为 `gpt-realtime-2.1`，音色 `marin`，接口根地址为 `https://api.openai.com/v1`。使用 Realtime API 的 WebRTC unified interface，非旧版 `/realtime/sessions`。[OpenAI 官方文档](https://developers.openai.com/api/docs/guides/voice-webrtc?api=realtime)

实时模型的声音与普通 TTS 分开设置。不能假定普通 TTS 音色名可用于实时模型。语义接话适合等用户表达完整意思；快速接话按所选停顿时间判断结束，较短停顿可能在句中断句。服务商按所选实时模型计费；默认通话上限为 5 分钟，可调整为 1、15 或 30 分钟，同时遵循「对话设置」的生成次数上限。不会自动重连或自动降级为另一条计费链路。

百炼的新配置默认使用「停顿后快速接话」和 700 ms 停顿，仍可切换为语义接话。已有配置保留原来的选择。本轮虚拟语音测试中，语义模式漏接过一段完整赞美；相同样本在停顿模式下正常识别、接话并触发害羞反应。语义判断和实际环境仍需使用者试听调整。

## 数据与声音

- 使用同一个 WebRTC 会话持续发送和接收音轨，不为每句话上传录音或重新调用 TTS。
- 角色人设、风格与讨论深度进入会话指令。复用当前角色组合和公开范围的同一份档案、历史摘要及长期记忆；存档作为用户会话数据补入，不提升为系统指令。公开通话不读取私聊记录或私密记忆。私聊通话中打开输出窗口、录制、联播或直播间时，通话会结束，需要重新开始（公开）。
- 通话开始时载入可用记忆，新条目在下次通话载入；「记住：……」仍可保存明确事实。修改、删除或关闭记忆，以及删除当前存档，会结束通话，避免上游继续沿用已撤销内容。Realtime 本身不额外请求文本模型生成摘要，已有摘要仍可用于衔接。
- 麦克风遵循统一声音控制的静音和增益；角色声音遵循角色及角色总线音量。实时音轨驱动口型，并可供联播与录制使用。
- 模型返回的字幕逐段更新。生成完成与音频播放结束分别处理；字幕草稿只在已检测到实际播放后进入记录，并保持未完整状态；音频正常排空后才确认完整。插话标记未说完的回复，迟到字幕不能补入被取消的回复。原生语音不保证逐字截断后的准确文字；不完整回复不会作为完整已说内容进入后续上下文。
- 通话期间禁用单句删除，避免本地删掉记录而上游会话仍记得。可结束通话后删除，再开始新的会话；清空会话会先结束通话。
- 实时声路报告角色发声、整轮结束和中断，供通用外部集成使用。带其他角色目标的事件明确拒绝，不会改由通话角色回答。
- 实时模型的 `stage_reaction` 工具把内容判断交给同一个角色反应模块，受角色的反应设置与人工控制优先级约束。等待和思考等基础状态不会占用内容反应间隔。工具只返回动作时最多续答一次，续答仍计入生成次数；停止和插话取消旧工具与待续播。[实现与验收范围](first-run-and-voice.md#实时语音内容反应2026-11-15)。
- 通话不读取屏幕或摄像头，不依赖 Neuro 模块。连接模块不导入 Stage、React、Player 或记忆存储；Stage 适配层负责角色、控制与字幕。

## 验证

连接层测试：

```sh
npm --prefix stage test
```

启动本机 Vite 后，以本机 WebRTC 对端和合成音频验证流式接收、插话、麦克风静音、暂停、口型及录制：

```sh
STAGE_TEST_URL=http://127.0.0.1:5222 node stage/test/realtime.mjs
REALTIME_TEST_PROVIDER=openai STAGE_TEST_URL=http://127.0.0.1:5222 node stage/test/realtime.mjs
```

本机模拟服务不调用付费模型。测试通过不代表账户权限、云端模型质量、真实网络延迟或扬声器环境下的回声已验收；真实云端与设备联调需分别记录结果。

百炼真实服务已使用独立配置及预录中文语音做过连续接话、上下文追问、语音插话和内容反应检查。实时模型是否调用反应工具仍有差异，提示明确区分庆祝、赞美等情绪事件与普通事实追问。联调曾收到一次百炼 `InternalError.Algo.ModelServingError`；此类错误会显示服务暂时出错并结束通话，不提示用户更换密钥，也不自动重试计费。真人麦克风和外放回声尚未验收。
