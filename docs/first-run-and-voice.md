# 首次使用与声音

## 首次体验

开始页提供 Nana（精修版）、Sena 与 Kai 的一键三人聊天演示「第一次同台」：6 句、约 20 秒，声音、动作与字幕都随应用提供。看演示不需要账户或 API Key，也不消耗模型用量。繁体中文、英文和日文界面播放对应语言的台词和配音。旧的 8 句双人脚本仍可打开。

我来演和 AI 来开播默认用 Nana 精修版；做一段视频默认 Sena/Kai（双人聊天）；三人闲聊由 Nana 精修版居中主持。精选角色优先显示 Nana 精修版、Sena、Kai，其余角色仍可添加。每个目标的准备清单直接通向角色卡、「设置 → 连接」和输出，不遮挡舞台。角色卡分三页：身体、谁来演、人设和声音；声音只在角色卡里选。

左右侧栏使用同一个收纳组件：左边「舞台内容」，右边按选中内容显示「角色设置」或「舞台设置」。收起时释放舞台空间，角色实例保留。

演示字幕标明姓名、整句呈现、按语义换行，并短暂保留上一句。声音提前准备一条，停顿按台本设置；演示不受 AI 对话的句数上限影响，停止会取消正在准备的声音。结束后可以「再看一次」，或者点「用你的模型重来一遍」：打开准备清单，接上自己的模型后，同样三个角色就能开始真实对话。看演示不算完成准备清单里的任何一项。

## 推荐的对话设置

1. 在「设置 → 连接」的文字模型选择阿里云百炼，填写自己的 Key。新设置优先选择 qwen-flash，采用非思考模式，适合短句交互。
2. 没有单独设置语音时，同一份百炼 Key 自动接 qwen-audio-3.1-tts-flash。Nana、Sena、Kai 分别默认龙安灵希、龙安欢、龙安朗，可以按角色改音色与语速。默认角色换顺序或单人使用时音色不变；明确选择的角色或全局音色优先。
3. 百炼 Key 同时接 qwen-audio-3.0-asr-flash：按住底部麦克风说话、松开发送，不需要登录 livliv.ai。麦克风驱动角色和录进自己的声音也不需要帐号。
4. 「设置 → 连接」最上面是「用 livliv.ai」（按积分）。打开后可以分别开关「文字」和「声音」（声音包括语音识别）：开着的部分由 livliv.ai 提供，关着的部分用自己的服务；两个都关就是关掉 livliv.ai。关掉时不消耗积分。
5. livliv.ai 的声音开着时，LivLiv 的角色用自己在站内的声音，其他角色（VRM、立绘、导入的模型包）用 livliv.ai 的系统音色，默认按性别分配，在角色卡「人设和声音」里可以换。某个角色也可以单独选「自己的服务」或「系统朗读」，不消耗积分。
6. livliv.ai 的文字和自己的模型一样，按角色卡的人设写台词，单角色会话也可以用 AIRI。

一次会话开始时没开 livliv.ai，中途打开也不会改用积分：这次会话的台词、声音和识别都照旧，下一次开始才生效。中途关掉则下一句起就不再消耗积分。

其他文本模型也可以用：OpenAI、DeepSeek、Kimi、智谱、硅基流动、OpenRouter、本机的 Ollama，或任何 OpenAI 兼容的接口。切换服务商会清空另一家的密钥，进行中的模型列表请求会取消。演示模式不覆盖先前的 API 配置。声音文件下载不转发生成接口的 Authorization。

OpenAI 旧 Speech API 保留为需要明确选择的兼容配置。它的 gpt-4o-mini-tts 将于 2027-01-06 停用，接替模型的接口流程不同，所以不会从 OpenAI 文本 Key 自动启用。[OpenAI 说明](https://developers.openai.com/api/docs/guides/text-to-speech)

语音识别把静音返回为错误时，界面显示「没听清，请再说一次」；其他接口错误照常报告。

参考：[百炼语音选型](https://help.aliyun.com/zh/model-studio/tts-model)、[原生 HTTP 参数](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)、[百炼音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)、[语音识别接口](https://help.aliyun.com/zh/model-studio/qwen-audio-3-0-asr-flash)。

## 本机免费的声音：Voicebox（桌面版）

[Voicebox](https://voicebox.sh) 是一个在自己电脑上运行的开源语音工具（MIT 许可），免费，台词不出这台电脑。桌面版 LivLiv Stage 会自己找它：启动时找一次，打开声音设置或角色卡的「人设和声音」时再找一次。

1. 从 [voicebox.sh](https://voicebox.sh) 下载并打开 Voicebox，在里面下载语音模型，添加一个声音：预设声音，或者用自己的录音克隆一个。
2. 回到 Stage。没有设置别的声音时，角色就用 Voicebox 说话；每个角色默认分到不同的声音，只用模型已经下载好的声音。准备清单的「声音」项会显示用的是哪个声音。
3. 想换声音，在角色卡「人设和声音」里选：这里列出 Voicebox 里的所有声音，包括你克隆的；模型还没下载的会标出来。Stage 自己不录音，也不克隆声音，也不替你下载模型。
4. 「设置 → 连接」的语音里可以选 Voicebox，点「测试」试听。识别默认不变：找到 Voicebox 不会改掉你原来的语音识别。想用它识别，打开「也用它听你说话」：按住说和免按键就用 Voicebox 的 Whisper 在本机识别，算作你自己的语音识别，不消耗 livliv.ai 积分。

Voicebox 没在运行、还没有声音、声音的模型还没下载（界面会说在 Voicebox 里怎么下载）、模型正在下载时，界面会直接说明。没找到 Voicebox 时，准备清单的「声音」项会给出下载链接。网页版不能用 Voicebox：它只接受自己页面的请求，所以由桌面版代为调用。

一次对话开始时用的是免费的声音和识别，中途 Voicebox 关掉了，也不会改用要积分的声音或识别：这时台词只出字幕，免按键停下并说明原因。

许可：Voicebox 本身是 MIT 许可。Stage 默认只用开放许可的引擎：Qwen3-TTS 及其 CustomVoice、VoiceDesign，还有 Kokoro（Apache-2.0）、Chatterbox（MIT）；识别用的 Whisper 是 MIT 许可。HumeAI TADA（Llama 3.2 许可）和 OmniVoice（非商用权重）的声音不会被默认选中，只有在角色卡里手动选了才会用。

## 动作细调

「动作细调与预设」独立于输入来源。待机、鼠标、摄像头、回放、麦克风、手柄、网络追踪和 AI 语音在最后合成角色参数时使用同一份映射。支持 Player 的 12 个标准通道，不是任意模型内部参数的编辑器。摄像头校准、帧率和手柄死区留在设备设置中，动作预设不改变它们。

Player 的最终姿势已包含映射，独立输出、好友联播与录制通过 `renderPose` 回放，不重复映射。旧的 tracking 预设文件仍可读取。
