# Security

Please report security problems by email to **admin@livliv.ai**, not in a public issue. Say what you found, how to
reproduce it and which version you used. We will reply by email and tell you when a fix is released. Please give us a
reasonable time to fix it before you make it public.

What counts: anything that a file or another party can make Stage do beyond its job, such as running code, reading or
sending your data, exposing your AI keys or the local control API's token, or reaching outside what it was given.
That includes project files, character packages and pictures; co-streaming peers and signalling servers; live chat
messages; requests to the desktop app's local control API and UDP inputs; and pages the desktop app loads.

Problems in character rendering or in model files themselves belong to [LivLiv Player](https://github.com/livliv-dev/player/blob/main/SECURITY.md).

Supported: the main branch until there are releases, then the latest release.
